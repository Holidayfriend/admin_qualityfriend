Daily commands
--------------
Run these from C:\laragon\www\app_qualityfriend.

Start all services:
  docker compose up -d

Stop all services without deleting database data:
  docker compose down

Build/recreate only Admin without touching dependencies:
  docker compose up -d --build --no-deps admin

Restart Admin after adding nested routes on a Windows bind mount:
  docker compose restart admin

Inspect status:
  docker compose ps

View Admin logs:
  docker compose logs --tail=100 -f admin

View Main App logs:
  docker compose logs --tail=100 -f app

View PostgreSQL logs:
  docker compose logs --tail=100 -f postgres

Verify endpoints in PowerShell:
  Invoke-WebRequest -UseBasicParsing http://localhost:3000
  Invoke-WebRequest -UseBasicParsing http://localhost:3000/api/health/database
  Invoke-WebRequest -UseBasicParsing http://localhost:3001
  Invoke-WebRequest -UseBasicParsing http://localhost:3001/api/health/database

WARNING: Never run docker compose down -v for routine development. The -v flag
deletes Compose volumes, including the persistent PostgreSQL data volume.
